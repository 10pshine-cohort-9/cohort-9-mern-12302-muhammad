# NotesApp Frontend

This is the frontend application for NotesApp, built with React and Vite.

## Features
- User Authentication (Login / Signup)
- Protected Dashboard Route
- Notes Management (coming soon)

## Development Commands
- `npm run dev` - Start the development server
- `npm run build` - Build for production
- `npm run lint` - Run Oxlint for code quality

## Backend Configuration
The frontend communicates with the backend API at `http://localhost:5000/api`. Ensure the backend server is running for full functionality.

## Extending the Setup
If you plan to introduce TypeScript-related tools or configurations later, refer to the Vite documentation.
